# V5：选择性分支恢复与低延迟完成通路

基于 V4 提交 `98d4abd`，保持 RV32IM 单发射乱序执行、按序提交和课程顶层接口。本版目标是 IPC 几何平均 0.845、频率超过 300 MHz、总面积不超过 18,000 μm²。频率、面积及全部正确性回归通过，IPC 目标尚未达到。完整数据与源码摘要见 [v5-results.json](v5-results.json)，历史结果见 [V4](v4.md)，当前结构见 [arch.md](../arch.md)。

## 恢复、完成与访存

- **选择性提前恢复**：控制指令分配时保存 RAT，包含 JAL/JALR 自身链接目的映射。EX 检出错误后下一拍恢复，保留分支及全部更老指令；重建 ROB/LSQ 数量和队尾，释放被杀目的寄存器。存活的旧 IQ、Load、Store、乘除结果不必重新执行。检查点满时仅阻塞新的控制指令分配。
- **恢复拍守恒**：检测拍阻止继续选入新的 EX 指令，避免下一拍误清老工作；恢复拍暂停提交、分配及后端 D/乘除响应消费，前端旧 I 响应和 AXI 事务仍可排空。旧 Load/乘除结果握住后继续完成。持久队列内的年轻 Load 标记 killed，保留原身份直到响应排空；已退休 Store 永远不因恢复取消。更老分支可以覆盖年轻分支已经进行的恢复。
- **前端提前重取**：每个接受请求保存独立取消位，恢复时标记旧请求，空闲信用可立即发出新路径；没有会回绕混淆的有限 epoch。默认无 RAS 时，恢复当拍即可发出目标请求。空指令 FIFO 支持响应直通；解码背压时保存原载荷。
- **方向预测**：PC 的相邻字段异或索引减少冲突，完整 PC tag 保留。每个 BTB 项的 1 位局部历史选择两位计数器，并由两位 chooser 与原 bimodal 预测混合。训练控制按行寄存，避免单个 taken 信号驱动全表。
- **并行完成**：普通 EX 可与一笔 Load 或 MDU 结果同拍完成，两个目的分别更新 PRF、ROB、IQ 就绪状态与重命名旁路；Load 与 MDU 之间仍有优先级。仍是单发射、单提交，不能把两笔完成称为双发射。
- **低延迟访存**：Cache 空响应 FIFO 可直接返回同步查询的命中结果；若背压则捕获保存，原有队列响应优先。无更早未发送请求时，RAM Load 可在分配持久描述符的同拍发给 Cache；被反压时下一拍由同一队列项接管。MMIO 保持原串行屏障。
- **连续 Store**：Store hit 写数据 SRAM 的同时，下一笔 Store 可查询独立标签 SRAM；Store 请求不启动无用的数据读。连续 Store hit 可每拍一条，Store→Load 保留单端口所需的间隔，确保读到已更新字节。

Miss 仍等全部 R 返回并合并错误后才产生结果，未采用忽略行尾错误的提前返回。脏行写回必须排空所有 B 且成功后才能清脏。失败保留原标签与脏数据，不安装替换行，不向外部发送后续 MMIO。已退休 RAM Store 的异步错误继续用描述符保存的原 PC/指令诊断并停止；不承诺回滚已提交的年轻指令。

对最终退休的误预测控制指令，统计“EX 检出误预测 → 下一条架构指令进入后端”的间隔。六程序事件加权平均从 V4 的 **6.306445 拍**降至 **2.076890 拍**，下降约 67.1%；事件数分别为 11,653 与 11,458，qsort 中位数从 6 拍降至 2 拍。下一条指令的 PC 必须等于实际重定向目标。此指标衡量重启延迟，不能直接累加为可删除的 CPI。

## 关键路径与设计取舍

IQ 保存发射所需的执行载荷，one-hot grant 直接选择，避免再以二进制 IQ/ROB 索引读取宽元数据。每行写回命中比较同时用于唤醒与操作数旁路，避免选出物理源寄存器后再次比较。普通 EX 使用独立完成端口，其唤醒不经过 Load/MDU 仲裁。Load 的原始完成候选不包含恢复拍的 ready，真实写入仍受恢复约束。

正常 PC 与恢复 PC 分别完成预测查询，再选择完整预测结果，避免恢复控制经过宽 PC 选择后驱动全表比较。训练控制按表项寄存。取指载荷由队列是否为空选择，和最终有效性分开；指令 FIFO 与请求上下文在有安全空闲尾项时预写，真实握手只授权有效状态。

I/D Cache 在 lookup 槽可用时允许内部 SRAM 预读并准备载荷，仍只有 `valid && ready` 能建立有效请求、增加信用或触发后续副作用。旧命中先消费或保存，缺失与写入继续占有单端口；未接受请求不能写数据、安装标签或发外部事务。这样将高扇出的宽载荷写使能从请求握手路径移开。RAM Load 直通资格也直接由本地资源与地址范围生成，不再重复经过完整 Load/Store 仲裁。以上改动保持周期行为，没有修改约束或 SRAM 模型。

最终最差路径为 D Cache 命中判断 → Load/MDU 写回匹配 → IQ 候选与最老选择 → 操作数旁路 → EX。主要剩余负载集中在发射 grant 对宽载荷的选择；报告未通过放宽约束或排除该路径取得频率。

| 同口径阶段或对照 | IPC 几何平均 |
| --- | ---: |
| V4 | 0.608254 |
| 检查点与选择性恢复 | 0.612617 |
| 增加并行完成 | 0.653637 |
| D 命中直通、前端重叠与局部预测 | 0.708678 |
| 再加 I 命中直通 | 0.722982 |
| 恢复当拍发出请求 | 0.738112 |
| Load 请求旁路 | 0.747407 |
| D256 B / I128 B | 0.756400 |
| 连续 Store 命中 | **0.759823** |

同一快速路径下，BTB=128 仅把 0.738112 提高到 0.738422；局部历史 2/3 位收益也很小。ROB=24/PRF=64/IQ=12/LSQ=12 仅达到 0.739644，故保留小窗口。公共 32/64 B 行分别退至 0.666068/0.714766；512 B 大行也不如 256 B。执行阶段训练仅有约 0.02% 收益，默认保持提交训练。上述对照的参数、日志和逐项周期保存在结果 JSON 与本地构建记录中。

当前短板集中在数据相关条件分支、阻塞式整行填充及退出写回。基于逐提交轨迹的全局预测离线筛选没有显示足以补齐 0.845 的收益；它是理想有序训练分析，不是硬件成绩。单独把外部延迟从 10 降为 1 的真实实验也只把对应 0.7474 阶段提升到 0.7702。D Cache 扩至 32 KiB 仅数据 SRAM 就增加约 5,504 μm²，超出当前预算。因此本版没有为了目标数值放宽错误、退出或计时规则；下一阶段应评估更宽执行前端，或带完整错误处理的非阻塞缓存。
